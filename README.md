# Harvard CS50's Introduction to Artificial Intelligence with Python

This repository contains my projects and exercises developed throughout [Harvard's CS50 Introduction to Artificial Intelligence with Python](https://cs50.harvard.edu/ai/).

The course explores fundamental concepts in Artificial Intelligence, including search algorithms, knowledge representation, uncertainty, optimization, machine learning, neural networks, and natural language processing.
